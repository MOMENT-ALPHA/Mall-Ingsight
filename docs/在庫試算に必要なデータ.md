# 在庫試算に必要なデータ

## 段階1：基礎データと基本指標

| 機能 | 内容 |
| --- | --- |
| **SKU別現在庫** | **用途：** 現時点の在庫状況を把握する<br>**説明：** SKUごとの現在保有している販売可能在庫数。各モール在庫や倉庫在庫を統合して確認する基礎データ<br>**算出方法：** `販売可能在庫 = 実在庫 - 引当済在庫`<br>※在庫定義は各システムに合わせて統一 |
| **SKU別30/60/90日販売数** | **用途：** 直近の販売実績と販売ペースを把握する<br>**説明：** SKUごとに直近30日、60日、90日の販売数量を集計し、短期・中期の販売傾向を比較する<br>**算出方法：** `対象期間内の販売数量合計`<br>※返品・キャンセルは原則除外 |
| **平均日販** | **用途：** 将来販売数や在庫消化速度を算出する<br>**説明：** 1日あたり平均何個売れているかを示す指標。販売予測の基礎となる<br>**算出方法：** `平均日販 = 対象期間販売数 ÷ 販売可能日数`<br>※欠品日は可能であれば除外 |
| **在庫日数** | **用途：** 現在庫が何日持つかを把握する<br>**説明：** 現在の販売ペースが続いた場合に、在庫が何日分残っているかを示す<br>**算出方法：** `在庫日数 = 現在庫 ÷ 平均日販` |
| **入荷予定** | **用途：** 将来在庫を正確に予測する<br>**説明：** 発注済みで今後入荷する予定数量と予定日を管理する<br>**取得項目：** 発注データから `入荷予定日・SKU・入荷予定数量` を取得 |
| **12か月在庫推移** | **用途：** 中長期の欠品・過剰在庫を予測する<br>**説明：** 現在庫、販売予測、入荷予定をもとに、今後12か月の月末在庫を試算する<br>**算出方法：** `翌月在庫 = 当月在庫 + 入荷予定数 - 販売予測数` を12か月繰り返す |
| **欠品予測日** | **用途：** 在庫切れの発生時期を事前に把握する<br>**説明：** 現在の在庫と販売ペースから、在庫が0になる見込み日を算出する<br>**算出方法：** `欠品予測日 = 基準日 + 在庫日数`<br>※入荷予定がある場合は日次シミュレーションで算出 |
| **欠品警告** | **用途：** 発注や在庫移動が必要な商品を早期発見する<br>**説明：** 欠品予測日や在庫日数が一定基準を下回ったSKUを警告表示する<br>**判定例：** `在庫日数 < 調達リードタイム + 安全在庫日数` の場合に警告 |

## 段階2：需要予測と発注判断

| 機能 | 内容 |
| --- | --- |
| **季節係数** | **用途：** 季節による販売量の増減を需要予測へ反映する<br>**説明：** サングラスなど季節性のある商品の月別需要差を数値化する<br>**算出例：** `季節係数 = 対象月の平均販売数 ÷ 全月平均販売数`<br>※複数年平均を推奨 |
| **販売トレンド** | **用途：** 最近の売上増加・減少傾向を予測に反映する<br>**説明：** 過去の平均だけではなく、直近で売れ行きが伸びているか落ちているかを判定する<br>**算出例：** `直近30日平均日販 ÷ 直近90日平均日販`<br>または30/60/90日の加重平均 |
| **SALE補正** | **用途：** セールによる一時的な販売増加を通常需要と分離する<br>**説明：** スーパーSALE等による販売急増を通常の販売力と誤認しないように補正する<br>**算出方法：** `通常需要 + SALE増加分` として別計算。過去SALE時の通常期間比からSALE係数を算出 |
| **安全在庫** | **用途：** 販売予測誤差や入荷遅延による欠品を防ぐ<br>**説明：** 予測販売数とは別に、需要変動に備えて確保しておく在庫<br>**算出方法：** `安全在庫 = 平均日販 × 安全在庫日数`<br>※高度化する場合は標準偏差を利用 |
| **推奨発注数** | **用途：** 必要な追加発注数量を算出する<br>**説明：** 将来需要、現在庫、入荷予定、安全在庫をもとに発注必要数を提示する<br>**算出方法：** `推奨発注数 = 予測期間需要 + 安全在庫 - 現在庫 - 発注済数量`<br>※0未満なら0 |

## 段階3：分析と精度改善

| 機能 | 内容 |
| --- | --- |
| **欠品機会損失** | **用途：** 在庫不足による売上損失を可視化する<br>**説明：** 欠品によって販売できなかったと推定される数量・売上・粗利を算出する<br>**算出方法：** `推定欠品数量 = 想定日販 × 欠品日数`<br>`機会損失売上 = 推定欠品数量 × 平均販売単価` |
| **過剰在庫分析** | **用途：** 売れ残りや資金滞留リスクを把握する<br>**説明：** 販売速度に対して在庫量が多すぎるSKUを特定する<br>**算出方法：** `在庫月数 = 現在庫 ÷ 平均月販`<br>基準月数超過分を過剰在庫として判定 |
| **需要予測精度検証** | **用途：** 在庫試算ロジックを継続的に改善する<br>**説明：** 過去に予測した販売数と実際の販売数を比較し、予測精度を評価する<br>**算出方法：** `予測誤差 = 実績 - 予測`<br>`誤差率 = ABS(実績 - 予測) ÷ 実績`<br>※MAPE等も利用可能 |
| **モール別需要分析** | **用途：** モールごとの需要差を把握し在庫配分を最適化する<br>**説明：** Amazon・楽天・Yahoo!等ごとの販売構成や成長率を分析する<br>**算出方法：** `モール構成比 = モール販売数 ÷ 全モール販売数`<br>期間別・SKU別に比較 |
