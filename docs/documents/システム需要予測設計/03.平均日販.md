# 平均日販

- 作成日：2026年8月28日
- 更新日：2026年8月28日
- 対象システム：ECモール統合分析システム「Mall Insight」
- 参照資料：[[要件定義書#FR-010 平均日販の算出|要件定義書.FR-10]] 

本書は、平均日販および基準平均日販の算出を定める。全体の位置づけは [[01.システム需要予測設計#2. 予測の全体像|システム需要予測設計.第2章]] の工程02である。算出・保存対象は、予測バージョンが参照する選定バージョンの対象SKUとする。入力となる補正済み実績と販売可能日数は [[02.予測用実績の補正]] で求める。

## 1. この工程で決めること

平均日販は「1日に平均何個売れるか」であり、すべての予測方式の出発点である。ここでは次を定める。

- 30日・60日・90日それぞれの平均日販の求め方
- 3つを1つにまとめた基準平均日販の求め方
- 実績が足りない期間を外したときの重みの直し方

## 2. 基本式

```text
平均日販 = 対象期間の補正済み純販売数量 ÷ 対象期間の販売可能日数
```

分母は暦日数ではなく販売可能日数である（[[02.予測用実績の補正#4. 販売可能日数|02.第4章]]）。

## 3. 期間別平均日販

期間は30日、60日、90日の3種類とし、いずれも基準日の前日から遡って数える。

```text
対象期間 = 基準日 - N日 〜 基準日 - 1日（N = 30, 60, 90）
```

- 基準日当日を含めない。当日分の実績は取込が完了しておらず、販売数量が確定しないためである。
- 3つの期間は重なり合う。60日平均は直近60日全体の平均であり、31日目〜60日目だけの平均ではない。
- 期間が発売日前または終売日後にかかる場合は、その日を販売可能日数から除く。

## 4. 基準平均日販

3つの期間の平均日販を、重みを付けて1つにまとめた値を基準平均日販とする。直近の変化を取り込みつつ、1か月だけの偶然の増減に振り回されないようにするためである。

```text
基準平均日販 = 30日平均日販 × 30日重み
             + 60日平均日販 × 60日重み
             + 90日平均日販 × 90日重み
30日重み + 60日重み + 90日重み = 1
```

重みはシステム全体で共通の設定値とし、品番・カテゴリー・SKU別には設定しない（[[要件定義書#FR-010 平均日販の算出|要件定義書義書.FR-010]]）。初期値は30日 0.5、60日 0.3、90日 0.2とする。設定時に合計が1であることを検証し、1でない場合はエラーとする（[[09.予測エラー・警告.md|09]]）。

### 4.1 算出例

| 期間 | 補正済み販売数量 | 販売可能日数 | 平均日販 | 重み |
| --- | --- | --- | --- | --- |
| 30日 | 60個 | 25日 | 2.40 | 0.5 |
| 60日 | 108個 | 54日 | 2.00 | 0.3 |
| 90日 | 150個 | 84日 | 1.79 | 0.2 |

```text
基準平均日販 = 2.40 × 0.5 + 2.00 × 0.3 + 1.79 × 0.2 = 2.158
```

直近30日だけを見れば2.40だが、より長い期間では1.79であり、直近が伸びている状態である。基準平均日販2.158は、その伸びを一部だけ織り込んだ値になる。

## 5. 期間の除外と重みの再正規化

次のいずれかに該当する期間は、平均日販を算出できないものとして計算対象から除外する。

- 販売可能日数が0である。
- 販売可能日数が最低販売可能日数（初期値14日）未満である。

除外した期間の重みを0とし、残る期間の重みの合計が1になるよう比例配分で割り戻す。

```text
再正規化後の重み = 元の重み ÷ 残る期間の元の重みの合計
```

### 5.1 再正規化の例

発売から45日しか経過しておらず、90日期間の販売可能日数が不足するSKUの例である。

| 期間 | 状態 | 元の重み | 再正規化後の重み |
| --- | --- | --- | --- |
| 30日 | 使用する | 0.5 | 0.5 ÷ 0.8 = 0.625 |
| 60日 | 使用する | 0.3 | 0.3 ÷ 0.8 = 0.375 |
| 90日 | 除外する | 0.2 | 0 |

除外した期間の平均日販を0として計算に入れない。0として扱うと、実績がないだけの商品の需要を不当に低く算出する。

3期間すべてが除外された場合は基準平均日販を算出せず、当該SKUを「予測不能」とし、補完の対象とする（[[07.実績不足時の補完と例外商品|07]]）。

## 6. 採用平均日販

予測方式によって、使用する平均日販が異なる。予測に実際に使用した値を *採用平均日販* と呼ぶ。

| 予測方式 | 採用平均日販 |
| --- | --- |
| 直近30日平均 | 30日平均日販 |
| 直近60日平均 | 60日平均日販 |
| 直近90日平均 | 90日平均日販 |
| 基準平均日販モデル、季節補正、季節・トレンド補正 | 基準平均日販 |

予測方式の選択は品番単位で行うが（[[06.バックテストとモデル選択#3. 方式を選ぶ単位|06.第3章]]）、採用平均日販はSKUごとの値を使用する。品番で選んだ方式に、SKU自身の平均日販を入れて予測する。

## 7. 保持する値

予測バージョン単位で次を保持する（[[08.予測バージョンと月次更新.md#6. 保存データと件数|08.第6章]]）。

| 項目              | 内容                   |
| --------------- | -------------------- |
| 期間別平均日販         | 30日・60日・90日それぞれの値    |
| 期間別の販売数量・販売可能日数 | 分子と分母。除外日数を含む        |
| 適用した重み          | 再正規化後の値。除外した期間が分かること |
| 基準平均日販          | 算出結果                 |
| 採用平均日販と採用理由     | 選択された方式に対応する値        |
| 算出日時            |                      |

除外した日の一覧は `販売実績補正` を参照して表示し、予測バージョン側に複製しない。

## 8. バックテスト時の扱い

バックテストでは、各起点の前日までの実績と、その時点の設定値だけを使用して平均日販を算出し直す（[[06.バックテストとモデル選択#8. 未来のデータを使わない|06.第8章]]）。起点より後の実績を分子にも分母にも使用しない。
