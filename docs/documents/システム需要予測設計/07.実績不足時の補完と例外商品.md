# 実績不足時の補完と例外商品

- 文書状態：初版案
- 版数：0.4
- 作成日：2026年8月28日
- 更新日：2026年8月31日
- 対象システム：ECモール統合分析システム「Mall Insight」
- 参照資料：[要件定義書](../要件定義書.md) FR-014、FR-018

本書は、実績が足りないSKU、新商品、終売品および商品マスタ未登録SKUの扱いを定める。全体の位置づけは[システム需要予測設計 第2章](01.システム需要予測設計.md)の工程05である。

## 1. この工程で決めること

過去の実績から予測する以上、実績のない商品は予測できない。しかし予測できないことと需要が0であることは違う。ここでは次を定める。

- 実績が足りないとき、どこから傾向を借りるか
- 借りられないとき、何をどう出すか

## 2. 不足の種類と影響

| 不足しているもの | 影響 | 対応 |
| --- | --- | --- |
| 直近の販売実績（平均日販が出ない） | すべてのモデルが算出できない | 第3.1節（階層を移らない）・第5章 |
| 複数年の実績（季節係数が出ない） | 季節補正・季節・トレンド補正が使えない | 第3章（上位階層へ移る） |
| 品番・カテゴリーの登録 | 適用する階層を特定できない | 第7章 |

## 3. 補完階層と算出単位

季節係数、トレンド係数および予測方式は品番単位を既定とし、実績の量に応じて上下の階層へ移る。この階層を補完階層と呼ぶ（[要件定義書 第5章](../要件定義書.md)）。

```text
SKU（十分な販売数量がある場合のみ）
  ↑既定はここ
品番（品番に属する全SKUの実績を合算）
  ↓不足
カテゴリー（商品マスタ登録済みでカテゴリーを判定できるSKUの実績を合算）
  ↓不足
既定モデル・予測不能
```

カテゴリー補完の集計元には、商品マスタに登録済みで、品番との対応およびカテゴリーを判定できるSKUの実績を使用する。対象品番以外のSKUもこの条件を満たせば含めるが、商品マスタ未登録、品番未設定またはカテゴリー未設定のSKUは含めない。補完した係数または方式を用いて需要予測を出力するのは、選定された対象品番のSKUだけとする。

| 対象 | 既定の単位 | 定義 |
| --- | --- | --- |
| 季節係数・トレンド係数 | 品番 | [04 第3章](04.季節係数・トレンド係数.md) |
| 予測方式の選択 | 品番 | [06 第3章](06.バックテストとモデル選択.md) |
| 平均日販・基準平均日販 | SKU | 階層を移らない（第3.1節） |

### 3.1 補完する対象

階層を移るのは季節係数、トレンド係数および予測方式だけとし、平均日販は移らない。

| 値 | 上位階層から借りるか | 理由 |
| --- | --- | --- |
| 季節係数・トレンド係数・予測方式 | 借りる | 月ごとの偏りや伸びの見方という「形」は、同じ品番・カテゴリーの商品で共通しやすい |
| 平均日販・基準平均日販 | 借りない | 何個売れるかの「水準」はSKUごとに大きく異なる。品番平均を借りると、売れないカラーの需要を過大に見積もる |

平均日販が算出できないSKUは、階層を移るのではなく第5章の新商品または第6章の予測不能として扱う。

### 3.2 補完階層の判定

| 判定 | 基準（初期値案） |
| --- | --- |
| SKU単位を採用する | そのSKU単体で12か月すべてについて同一月の有効実績が2年分以上あり、かつ対象期間の月平均販売数量が10個以上である（[04 第3章](04.季節係数・トレンド係数.md)） |
| 品番単位を採用する（既定） | 同一品番の全SKU合計で必要年数の条件を満たす |
| カテゴリーへ上げる | 品番でも満たさず、商品マスタ登録済みかつカテゴリー判定可能なSKUのカテゴリー合計で必要年数の条件を満たす |
| 算出不能 | 上記の対象SKUだけで集計したカテゴリーでも満たさない、または対象品番・カテゴリーが未登録 |

上位階層から得た係数はそのまま適用し、SKUの規模に合わせた調整を加えない。係数は倍率であり、水準を含まないためである。予測方式についても同様に、品番で選んだ方式をSKUごとに調整しない。

## 4. 補完階層の記録

自SKU以外の階層から係数または方式を適用した場合は、次を係数バージョンおよびモデル選択結果に保持し、画面で確認できるようにする（[要件定義書 FR-018](../要件定義書.md)）。

- 補完階層（SKU・品番・カテゴリー・類似商品・既定モデルのいずれか）
- 補完元の識別子（品番コード、カテゴリー、類似商品のSKU）
- カテゴリー補完に使用したSKUの抽出条件、件数および商品マスタの参照時点

需要予測一覧および品番・SKU詳細で、係数と予測方式がどの階層に由来するかを判別できるようにする。

## 5. 新商品

販売実績のない、または極端に短いSKUは、次の優先順で予測する。

| 優先 | 方法 | 内容 |
| --- | --- | --- |
| 1 | 手動初期予測 | 担当者が月別の予測値を直接入力する |
| 2 | 類似商品 | 指定した類似商品の平均日販と係数を使用する |
| 3 | 初回投入計画 | 初回投入数量と想定消化期間から平均日販を仮置きする |
| 4 | 予測不能 | 上記のいずれも設定されていない場合 |

- 類似商品は担当者が明示的に指定し、システムが自動で選定しない。選定根拠を保持する。
- 手動初期予測および類似商品による予測は、自SKUの平均日販を算出できるようになり、所属品番の係数と方式を適用できる状態になった時点で自動予測へ切り替える。切替の判定は月次予測更新で行い、切替時期を記録する。
- 新商品の予測はバックテストの評価対象としない。評価に足る起点がないためである。

## 6. 終売品

- 商品マスタの終売日が設定されたSKUは、終売日の属する月の翌月以降の需要予測を算出しない。
- 終売日が属する月は、月初から終売日までの日数を予測販売可能日数とする（[05 第4章](05.予測モデルと需要予測の算出.md)）。
- 終売品を予測不能として扱わない。予測を停止したことが分かる状態で出力する。
- 終売後の在庫は在庫試算の対象に残す。需要が0でも在庫は存在するためである。

## 7. 商品マスタの登録対象と未登録SKU

販売実績および在庫は全SKUについて保持するが、商品マスタへ品番・カテゴリー等の属性を登録する対象は、設定された判定期間内の販売数量が最低販売数量を満たすものに限定する。判定期間と最低販売数量は設定値とし、初期値は第9章の未確定事項とする。

取込時に識別したSKUは、商品マスタへ登録済みかどうかで次のように扱う。登録済みかは品番に所属しているかで判別し、SKUに登録状況を表す状態を保持しない（[商品管理要件 第5.3.1項](../商品管理要件/01.商品管理要件.md)）。

| 区分 | 条件 | 扱い |
| --- | --- | --- |
| 商品マスタ未登録 | 品番に所属していない | 販売実績・在庫は保持するが、売上上位品番の判定およびカテゴリー補完の集計元から除外する。取込では警告せず、商品・SKUマスタの未登録SKU一覧で担当者が販売数量順に処理する |
| 商品マスタ登録済み | 品番・カテゴリーおよび所属SKUの登録が完了している | 売上上位品番の判定対象とし、カテゴリーを判定できるSKUはカテゴリー補完の集計元に含める |

- 商品マスタ未登録のSKUは対象品番へ関連付けできないため、需要予測値または予測不能レコードを作成しない。0個の需要としても扱わない。
- 商品マスタ登録後、その品番が選定対象であれば、品番単位の係数と予測方式を適用し、以後の予測バージョンから予測値を出力する。
- 未登録SKUには品番が設定されていないため、登録基準の判定はSKU単位の純販売数量で行う。登録済み品番については品番別純販売数量で判定する。既に登録済みの商品は販売数量が低下しても自動削除しない。

## 8. 予測不能の扱い

本章は選定された対象SKUの算出が不能になった場合に適用する。対象外品番のSKUおよび商品マスタ未登録SKUについては、予測不能レコードを作成しない。

| 場面 | 扱い |
| --- | --- |
| 需要予測一覧 | 数量欄に0を表示せず「予測不能」と表示し、理由を併記する |
| 保存 | 予測値なし、状態「予測不能」、理由コードを予測バージョンへ保存する |
| 目標比較 | 差異および差異率を「算出対象外」とする |
| 在庫試算 | 需要値として使用しない。対象品番のSKUに含まれる場合は試算実行時に警告する |
| 集計 | 上位集計（品番計・カテゴリー計）で0として合算しない。集計値に予測不能を含むことを明示する |

## 9. 未確定事項

1. 平均日販を階層で移さない設計でよいか。品番内でカラー・度数の構成比が安定している場合、品番実績からの按分が有効な可能性がある。
2. 新商品の判定基準（販売開始からの日数、または累計販売数）。
3. 初回投入計画を保持するデータを新設するか、手動初期予測に一本化するか。
4. 類似商品による予測から自動予測へ切り替える条件と、切替時に予測値が不連続に変わることの扱い。
5. 予測不能のSKUが上位集計に与える影響の表示方法。
6. 商品マスタ登録基準に用いる判定期間と最低純販売数量。未登録SKUに適用するSKU単位の値と、登録済み品番に適用する品番単位の値を別に設けるか。
