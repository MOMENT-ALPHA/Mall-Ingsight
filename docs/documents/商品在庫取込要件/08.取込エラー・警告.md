# 取込エラー・警告

- 文書状態：確定版
- 更新日：2026年8月31日
- 対象システム：商品在庫管理システム

本書は、商品在庫取込で取込エラーまたは警告として扱う条件を定める。  
検出した内容を記録する取込指摘の保存項目は第5章に定める。

取込エラーは、対象範囲に応じてファイル全体、商品単位、行単位の3種類とする。  
警告は、可能な範囲で登録したうえで担当者の確認を促すために記録する。  
さらに、単独のファイルでは判定できない検証を倉庫横断の警告として第4章に定める。

## 1. ファイル全体の取込エラー

次の場合はファイル全体を登録せず、取込エラーとして記録する。

- ファイルの文字コードまたは区切り文字を判定できない。
- 対象ファイル種別に必要な必須列が存在しない。
- ファイル種別または取込元を識別できない。
- 在庫基準日が指定されていない。
- 指定された在庫基準日が未来日である。

## 2. 商品・行単位の取込エラー

次の場合は該当商品の全倉庫区分の在庫数を登録・更新せず、商品単位の取込エラーとして記録する。該当しない他の商品は取込処理を継続する。

- BOSSの`実在庫数`と、同一`商品ID`の`実在庫 (倉庫毎)`の合計が一致しない。
- BOSSの`引当済 (全倉庫)`と、同一`商品ID`の`引当済 (倉庫毎)`の合計が一致しない。

次の場合は対象行を登録せず、行単位の取込エラーとして記録する。正常な他の行は取込処理を継続する。

- 取込対象行に、[BOSS各在庫数レポート取込要件 第2章](02.BOSS各在庫数レポート取込要件.md)、[Amazon出品詳細レポート取込要件 第2章](03.Amazon出品詳細レポート取込要件.md)または[Amazon FBA在庫レポート取込要件 第2章](04.AmazonFBA在庫レポート取込要件.md)で値を必須とした列の値が存在しない。
- 在庫数量の形式が不正である。
- BOSSの`倉庫`から倉庫区分を判定できない。
- Amazonファイルの同一ファイル内に同一の一意キーが複数存在する場合の、2行目以降の重複行。

[Amazon出品詳細レポート取込要件 第3章](03.Amazon出品詳細レポート取込要件.md)によりFBA出品として取込対象外とした行、および[Amazon FBA在庫レポート取込要件 第3章](04.AmazonFBA在庫レポート取込要件.md)により販売不可在庫として取込対象外とした行は、本章の行単位の取込エラーの対象としない。

## 3. 警告

次の場合は可能な範囲で登録し、確認用の警告を記録する。

### 3.1 商品コードに関する警告

- Amazonの`出品者SKU`または`seller-sku`が商品コード対応表に存在しない。当該行の在庫は登録しない。

### 3.2 入力値に関する警告

- BOSSの同一ファイル内に同一`商品ID`かつ同一`倉庫ID`の行が複数存在し、最初の1行を除く重複行を取込対象外とした。
- BOSSの`倉庫ID`と`倉庫`の対応が[BOSS各在庫数レポート取込要件 第5章](02.BOSS各在庫数レポート取込要件.md)の対応表と異なる。倉庫区分は`倉庫`から判定して登録する。
- BOSSの`セット区分`が`0`以外である。当該行は通常のSKUとして登録する。
- 販売可能在庫が負値である。`0`へ補正せず登録する。BOSSでは`引当済 (倉庫毎)`が`実在庫 (倉庫毎)`を超える場合、またはいずれかが負値の場合に発生する。
- FBA在庫レポートに`Warehouse-Condition-code`が`SELLABLE`以外の行が含まれている。当該行の在庫は登録しない。

### 3.3 取込結果に関する警告

- 直前の同一倉庫区分の取込に存在したSKUが、今回のファイルに存在しない。既存レコードは削除も`0`への書き換えもしない。
- 取得区分が`手入力`の既存レコードを含む倉庫区分・在庫基準日を再取込した。手入力のレコードは上書きしない。
- 既に在庫数が登録済みの在庫基準日を指定して再取込した。
- 指定された在庫基準日が、直近の在庫基準日より前である。

## 4. 倉庫横断の警告

次の検証は単独のファイルでは判定できないため、同一在庫基準日の全取込元の取込が完了した時点で判定し、警告として記録する（[取込処理・運用要件 第3章](07.取込処理・運用要件.md)）。

- 出品詳細レポートで`数量`が空欄であり、かつ同一在庫基準日のFBA在庫レポートにも存在しないSKUがある。当該SKUは、いずれの倉庫区分の在庫としても登録されていない。
- 同一の在庫基準日に、4つの倉庫区分すべての在庫が揃っていない。揃っていない倉庫区分を記録する。
- SKUマスタに存在するSKUのうち、当該在庫基準日にいずれの倉庫区分の在庫も登録されなかったものがある。

倉庫横断の警告は、いずれか1つの取込元の取込履歴に属さないため、当該在庫基準日で最後に完了した取込の取込履歴に記録する。

## 5. 取込指摘

エラーおよび警告は、画面表示だけで終了させず、次の項目を保存する。

| 保存項目 | 内容 |
|---|---|
| 取込指摘ID | システムが付与する内部ID |
| 取込履歴ID | 指摘を検出した取込履歴 |
| 重要度 | `エラー`または`警告` |
| 対象単位 | `ファイル`、`商品`、`行`または`倉庫横断` |
| 指摘コード | システム内で定義する指摘種別コード |
| 指摘内容 | 利用者向けの説明 |
| 元ファイル行番号 | 該当する入力行。ファイル全体および倉庫横断の指摘では`NULL` |
| 在庫基準日 | 対象の在庫基準日 |
| 倉庫区分 | 特定できた場合の倉庫区分 |
| 取込元SKU | 特定できた場合の取込元SKU |
| システム内商品コード | 特定できた場合のシステム内商品コード |
| 取込元商品ID | 特定できた場合の取込元商品ID |
| 詳細値 | 差分数量、重複件数、対象外行番号等 |
| 記録日時 | 指摘を記録した日時 |

保存項目の構成は[販売実績保存データ 第6章](../販売実績取込要件/04.販売実績保存データ.md)の取込指摘と共通とし、在庫に固有の項目として在庫基準日および倉庫区分を追加する。
